# Valaikappu Invitation — Vercel Ready

This folder contains the complete single-page invitation website.

## Files
- `index.html` — complete invitation, including the cover, inside invitation, door-opening animation, and embedded background audio.

All images and the uploaded audio are embedded in `index.html`, so no separate asset files are required.

## Publish free with Vercel
1. Create/sign in to GitHub.
2. Create a new repository (for example, `valaikappu-invitation`).
3. Upload `index.html` from this folder to the repository's root.
4. Sign in to Vercel with GitHub.
5. Choose **Add New → Project**, import that repository, and click **Deploy**.
6. Share the generated `*.vercel.app` URL on WhatsApp.

## Audio note
The page attempts to autoplay the embedded music when it loads. Browsers may block autoplay with sound until a visitor interacts with the page; this restriction cannot be overridden by the website.
